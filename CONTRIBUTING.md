# Contributing

Thanks for helping keep this list useful!

## Add a bot
The README and `categories/` are **generated** every day from the BotsDots catalog, so pull
requests that edit them directly would be overwritten. Instead:

1. **[Submit your bot on BotsDots](https://botsdots.site/submit)** — paste your public
   `https://x.ai/bot/…` link; it's checked automatically and reviewed.
2. Once approved, it appears on [botsdots.site](https://botsdots.site) and in this list on the
   next daily update.

## Fix or remove a listing
- Use **"Report a problem"** on the bot's page at botsdots.site, or
- open an [issue](../../issues) with the bot's x.ai link and what's wrong.

Creators can ask for their bot to be removed at any time — no reason needed.

## Improve the list itself
Changes to `scripts/build.mjs` (layout, sections, formatting) are very welcome as pull requests.
Run `node scripts/build.mjs` locally to preview the output.
